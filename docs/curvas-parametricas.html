Curvas Paramétricas — Bézier e Hermite

Trabalho Prático 02 — Computação Gráfica

Autor: Lucas Gualtieri · 2026

Documentação técnica do TP 02. Estende o TP 01 (matriz de pixels com retas, circunferência, recorte e transformações 2D) com duas curvas paramétricas vistas em sala: a curva de Bézier (avaliada pelo algoritmo de De Casteljau) e a curva de Hermite cúbica.

1. Organização do código

O projeto é uma aplicação web (Vite + TypeScript) que rasteriza primitivas diretamente sobre um buffer de pixels do <canvas>. O código é dividido em módulos com responsabilidades bem separadas (todos em src/):

MóduloResponsabilidade
types.tsTipos compartilhados: Point, VectorIJ, Color, Rect, Tool, UIState.
Algorithms.tsAlgoritmos puros de rasterização e geometria — recebem um PixelWriter (x, y, color) => void e não conhecem o canvas. É aqui que vivem as curvas.
Homogeneous2D.tsMatrizes homogêneas 3×3 (rotação, escala, translação) e suas operações.
CanvasManager.tsDono do buffer de pixels: setPixel, limpeza, grade e a conversão tela → coordenadas lógicas (picking).

main.tsOrquestrador. Mantém a lista de primitivas, o fluxo de cliques, o pipeline de transformação e o laço de redesenho.

2. Modelo matemático

Uma curva paramétrica é uma função P(t) que mapeia um parâmetro escalar t ∈ [0, 1] num ponto do plano. Em vez de descrever y em função de x (o que impede curvas verticais ou laços), descrevemos x e y separadamente em função de t. Tanto Bézier quanto Hermite são curvas polinomiais: cada coordenada é um polinômio em t.

2.1. Curva de Bézier — algoritmo de De Casteljau

Dados n+1 pontos de controle P0, P1, …, Pn, a curva de Bézier de grau n é

B(t) = ∑i=0n n!i! (n−i)! (1−t)n−i ti Pi,    t ∈ [0, 1].

Os coeficientes bi,n(t) são os polinômios de Bernstein. Em vez de avaliá-los diretamente, usamos o algoritmo de De Casteljau, numericamente mais estável e geometricamente intuitivo: ele é uma sequência de interpolações lineares.

Definimos Pi(0) = Pi e iteramos:

Pi(k) = (1−t) Pi(k−1) + t Pi+1(k−1),    k = 1…n,   i = 0…n−k.

Após n níveis resta um único ponto P0(n) = B(t). Esquema para n = 3:

P0   P1   P2   P3        (nível 0 — pontos de controle)
  Q0   Q1   Q2           Qi = lerp(Pi, Pi+1, t)
    R0   R1              Ri = lerp(Qi, Qi+1, t)
      S0                 S0 = lerp(R0, R1, t) = B(t)

Implementação (deCasteljau em Algorithms.ts): copiamos os pontos de controle para um vetor mutável e, a cada nível, substituímos cada posição pela interpolação dela com a vizinha, encurtando o vetor em 1 até sobrar um ponto.

Propriedades relevantes:

  • Interpolação dos extremos: B(0) = P0 e B(1) = Pn — a curva passa pelo primeiro e pelo último ponto de controle, mas apenas aproxima os intermediários.
  • Fecho convexo: a curva fica contida no fecho convexo dos pontos de controle.
  • Invariância afim: aplicar uma transformação afim M aos pontos de controle e depois avaliar dá o mesmo resultado que avaliar e depois transformar. Isso é o que nos permite transformar apenas os poucos pontos de controle e só então amostrar a curva — exatamente o que drawCurve faz em main.ts.

2.2. Curva de Hermite cúbica

A curva de Hermite é definida por dois pontos P0, P1 e duas tangentes (vetores velocidade) T0, T1 nesses pontos. A forma cúbica é

P(t) = H00(t) P0 + H10(t) T0 + H01(t) P1 + H11(t) T1,

com os polinômios de base de Hermite:

H00(t) = 2t3 − 3t2 + 1     H10(t) = t3 − 2t2 + t
H01(t) = −2t3 + 3t2         H11(t) = t3 − t2

Eles são construídos para satisfazer as condições de contorno:

P(0) = P0,    P(1) = P1,    P′(0) = T0,    P′(1) = T1.

Ou seja, a curva interpola os dois pontos e sai/chega com as tangentes prescritas — útil quando se quer controlar a direção e a "força" da curva nas pontas.

Entrada por alças. Tangentes são difíceis de clicar diretamente, então a interface usa alças: o usuário clica o ponto P0 e depois uma alça H0; a tangente é a diferença T0 = H0 − P0 (idem para P1, H1). Internamente a primitiva guarda os quatro pontos [P0, H0, P1, H1].

Tangentes sob transformação. Pontos são posições (transformam como A p + b), mas tangentes são vetores (transformam só pela parte linear, A v, sem a translação). Guardando a alça como posição e calculando a tangente como diferença depois de transformar, obtemos automaticamente o comportamento correto:

T0′ = H0′ − P0′ = (AH0 + b) − (AP0 + b) = A (H0 − P0) = A T0.

Por isso drawCurve transforma os quatro pontos como posições e só então recalcula as tangentes.

2.3. Amostragem e rasterização

Ambas as curvas são contínuas, mas a tela é discreta. Avaliamos a curva em tk = k/N para k = 0, 1, …, N (onde N = segments), obtendo N+1 pontos, e ligamos pontos consecutivos com Bresenham. Quanto maior N, mais fina a aproximação (refinamento controlado pelo slider segments).

3. Manual de uso

3.1. Executando

npm install     # instala dependências
npm run dev     # inicia o servidor de desenvolvimento (abra a URL exibida)
npm run build   # checagem de tipos + build de produção
macOS: se o build acusar "library load disallowed by system policy" no lightningcss, remova a quarentena do binário nativo: xattr -dr com.apple.quarantine node_modules/lightningcss-darwin-arm64/.

3.2. Desenhando uma curva de Bézier

  1. Na barra lateral, em Tool Selector, clique em Bézier.
  2. Clique no canvas para adicionar pontos de controle (quantos quiser, ≥ 2). O polígono de controle (linhas cinza) e os marcadores aparecem em tempo real.
  3. Clique em Finalizar curva (painel Curvas Paramétricas) para confirmar.
  4. Ajuste o slider segments para refinar/suavizar a curva.

3.3. Desenhando uma curva de Hermite

  1. Selecione a ferramenta Hermite.
  2. Dê 4 cliques nesta ordem:
    1. P0 — ponto inicial;
    2. alça de P0 — define a tangente T0 (direção/força de saída);
    3. P1 — ponto final;
    4. alça de P1 — define a tangente T1 (direção/força de chegada).
  3. A curva é finalizada automaticamente no 4º clique. As alças aparecem como linhas-guia ligando cada ponto à sua alça.

3.4. Transformações e demais controles

  • dx, dy, angle, sx, sy (painel Transformations) aplicam translação, rotação e escala a toda a cena — as curvas acompanham (invariância afim).
  • pixel size amplia os blocos lógicos; Grid mostra eixos e origem.
  • Clear Matrix limpa tudo, inclusive uma curva em construção.
  • Trocar de ferramenta descarta a curva ainda não finalizada.
